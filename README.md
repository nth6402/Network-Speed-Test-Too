# Network Speed Test & Traffic Analysis Tool

## Overview
This project is a Python-based application designed to measure network performance (Download, Upload, and Ping) and analyze the results based on Traffic Analysis concepts .

## Features
- Measures real-time Download and Upload speeds (in Mbps).
- Measures network Latency (Ping) in milliseconds.
- Analyzes the results to detect Bottlenecks or High Latency.
- Automatically saves the test history to a CSV file for future monitoring.

## How to Run
1. Install the required library:
   pip install speedtest-cli
2. Run the script:
   python speed.py

## Built With
- Python 3
- Tkinter (for GUI)
- Speedtest-cli (for network measurement)
